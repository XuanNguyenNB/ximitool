# Ximi Tool (Lite Version)

Đây là bản nén gọn của công cụ **Ximi AIO Unlock Tool**.
Toàn bộ script và các công cụ unlock được đóng gói trong tệp Ximi_tool_Lite.7z.

**Ghi chú:**
- Đã loại bỏ các file firmware nặng (.img, .bin...) từ actoryImages để tối ưu dung lượng (chỉ giữ lại abl.elf và gpt_both4.bin cần thiết cho Unlock).
- Nếu cần Flash Baseband, vui lòng tự copy firmware của máy vào thư mục tương ứng.
